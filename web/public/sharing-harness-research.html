02 / 07

inside the methodology

Superpowers 真正工程化在哪里？

BOOTSTRAP

自动进入

会话开始即加载 using-superpowers；行动前先检查是否有匹配 Skill。

HARD GATE

不允许跳步

设计需确认、测试先失败、Review 问题清零，关键节点都有门禁。

EVIDENCE

证据优先

验证命令与实际输出优先于“应该没问题”，完成声明必须可复查。

SKILL TDD

方法也要测试

用压力场景验证 Skill：先观察基线失败，再证明新纪律能改变行为。

收益 · 高一致性复杂任务有稳定节奏，关键质量动作不依赖模型临场自觉。
取舍 · 默认偏重worktree、TDD、subagent、commit 全程启用，对日常小改动成本较高。

来源：Superpowers README 与 Skills
