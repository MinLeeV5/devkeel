# 常见 UI 失真点

## 1. 结构失真

表现：

- 页面结构和设计图层级不一致
- 本应分离的区域被包进同一个容器
- 上层结构被错误下沉到页面内部

常见原因：

- 没先判断运行时层次
- 没先判断当前页面是否有宿主容器
- 直接从截图开始写样式

## 2. 空间节奏失真

表现：

- 单个控件尺寸差不多，但整体"不像"
- 元素间距离不对
- 页面上下显得过挤或过松

常见原因：

- 只盯尺寸，不看整体 rhythm
- 中途频繁局部补丁
- 忽略垂直节奏

## 3. 容器边界失真

表现：

- 左右边界不一致
- 顶部或底部透出异常颜色
- 某些区域偏白、偏灰、偏暗

常见原因：

- 背景层与覆盖层重叠错误
- 上层容器和页面背景同时生效
- 圆角容器与外层背景没有对齐

## 4. 资源失真

表现：

- 图标形状接近但风格不一致
- 激活态和未激活态资源不一致
- 自己造的资源和设计稿资源不一致

常见原因：

- 没优先使用设计稿提供的资源
- 用近似资源代替
- 忽略状态资源差异

## 5. 交互失真

表现：

- 静态图像看起来对，但点击流程不对
- tab 或方法切换后布局跳动
- 交互路径与设计意图不一致

常见原因：

- 只实现默认态
- 用截图猜交互
- 没把切换流程纳入设计对齐范围

## 6. 状态失真

表现：

- 默认态对了，其他状态完全不像
- 一个状态结构正确，另一个状态结构错位

常见原因：

- 实现范围没有显式定义
- 只做第一屏
- 没按状态逐个验收

## 7. 运行时错层

表现：

- 页面中重复出现外围壳子元素
- 顶部栏颜色、层级、按钮重复
- 页面试图模拟整个应用窗口

常见原因：

- 没确认宿主层和页面层边界
- 把整窗设计稿当成单页稿
- 没先看路由和容器代码
