# 自验清单

在声称"已按设计意图对齐"之前，至少逐项确认：

## 范围

- 本轮实现范围是否明确
- 是否覆盖了承诺范围内的关键状态
- 是否没有超出范围乱改无关层

## 分层

- 是否确认了运行时容器
- 是否区分了宿主层、页面层、组件层
- 是否避免重复实现上层结构

## 结构

- 主要容器关系是否正确
- 布局模型是否正确
- 条件显示和隐藏是否正确
- 滚动和裁切行为是否正确

## 视觉

- 关键尺寸是否对齐
- 间距节奏是否对齐
- 对齐关系是否对齐
- 背景、边界、圆角、阴影是否对齐
- 图标与图片资源是否一致

## 交互与状态

- 主要交互路径是否正确
- 切换态是否正确
- loading / empty / error / disabled 等必要状态是否合理
- 状态切换后布局是否仍然稳定

## 运行时验证

- 是否在真实运行容器中看过效果
- 是否确认没有上层样式叠加问题
- 是否确认真实组合效果而不是只看孤立页面

## 验证证据

- 是否运行了最接近改动的验证
- 是否说明了未验证项
- 是否说明了剩余风险
