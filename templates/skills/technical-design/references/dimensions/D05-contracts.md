# D05 契约与接口

## 目标

定义 API、CLI 参数、组件 props、SDK 类型、IPC、事件、消息、配置等对外或跨模块契约。

## 输出契约

- 契约对象：接口、命令、事件、配置、类型或消息名称。
- 输入：字段、类型、必填性、默认值、校验规则。
- 输出：成功结果、错误结果、退出码、事件 payload 或返回类型。
- 兼容：新增、废弃、破坏性变化和迁移策略。
- 错误模型：错误码、异常类型、用户提示或调用方处理方式。

## 完成检查

- [ ] 契约足够让实现和测试直接引用。
- [ ] 破坏性变化已标出并说明迁移。
- [ ] 错误结果不是事后补丁，有明确设计。
