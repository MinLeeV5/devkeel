# D04 流程与失败路径

## 目标

把核心流程、异常流程和恢复路径讲清楚，避免方案只覆盖 happy path。

## 输出契约

- 主流程：用户、系统或任务从入口到完成的关键步骤。
- 失败路径：输入非法、网络失败、权限失败、并发冲突、资源不可用等。
- 恢复策略：重试、回滚、补偿、降级、提示用户或人工介入。
- 状态变化：每一步前后关键状态如何变化。
- 时序图：流程跨多个模块或系统时优先用 Mermaid sequence diagram。

## 完成检查

- [ ] 主路径和至少关键失败路径均已覆盖。
- [ ] 失败处理不会制造更大的状态不一致。
- [ ] 用户可见失败有清晰反馈或恢复方式。
