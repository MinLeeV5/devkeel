# D10 安全与隐私

## 目标

在该维度被选择后，按领域 lens 输出安全与隐私设计。启用条件由 `dimension-selection.md` 和领域 profile 决定，本文件只定义启用后的输出契约。

## 输出契约

- 资产：需要保护的数据、凭证、权限、接口、文件或执行能力。
- 信任边界：用户输入、浏览器、renderer、preload、服务端、外部平台、本地文件系统等边界。
- 主要风险：列出与本次触点直接相关的风险，不做无关清单。
- 缓解策略：校验、最小权限、白名单、隔离、脱敏、审计、超时、限流。
- 验证方式：单测、集成测试、安全检查、手动复核或配置检查。

## Lens

| 领域 | 关注点 |
|------|--------|
| frontend | XSS、鉴权态、敏感信息暴露、跨域、三方脚本、日志脱敏 |
| backend-api | STRIDE 可作为高风险场景的完整分析工具；常规场景重点看认证授权、注入、越权、敏感数据、审计 |
| desktop | preload/IPC 白名单、context isolation、nodeIntegration、文件权限、原生能力最小暴露 |
| native-service | IPC ACL、服务账号权限、UAC/提权边界、系统 API 调用权限、文件/注册表/设备访问、调用方白名单 |
| mobile | 本地敏感数据、系统权限、剪贴板、截屏、深链、证书和鉴权态 |
| cli | token 存储、路径遍历、shell 注入、权限、stdout/stderr 泄露 |
| sdk | token 传递、默认配置、依赖供应链、调用方误用、错误信息泄露 |
| devops | 密钥、环境隔离、供应链、发布权限、审计、回滚权限 |
