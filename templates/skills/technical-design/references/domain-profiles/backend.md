# Backend Profile

适用于服务端 API、任务处理、存储、消息队列、后台运行时和跨系统集成。

| 维度 | 策略 | 默认优先级 | 触发条件 | 输出深度 |
|------|------|------------|----------|----------|
| D01 范围、目标与非目标 | 必选 | core | 任意后端变更 | 说明能力边界和非目标 |
| D02 架构边界与模块关系 | 必选 | core | 服务、模块、依赖或部署单元变化 | 展开边界、依赖方向和候选方案 |
| D03 运行边界与职责归属 | 条件 | supporting | 进程、任务、worker、服务职责变化 | 写清运行位置和职责 |
| D04 流程与失败路径 | 必选 | core | 请求链路、异步任务、批处理、消息消费 | 覆盖主流程、异常、重试和补偿 |
| D05 契约与接口 | 条件 | core | API、事件、消息、数据库访问契约变化 | 定义契约和兼容 |
| D06 数据与状态 | 条件 | core | 表、缓存、一致性、事务、状态机变化 | 展开数据模型和一致性 |
| D07 UI 与交互 | 跳过 | skip | 无 UI 输出 | 不展开 |
| D08 性能与资源 | 条件 | supporting | 吞吐、延迟、容量、批量任务、热点资源变化 | 按服务指标输出 |
| D09 可靠性与恢复 | 条件 | supporting | 故障传播、幂等、降级、恢复、主备 | 展开恢复和隔离策略 |
| D10 安全与隐私 | 条件 | supporting | 认证授权、注入、越权、敏感数据、外部入口 | 使用 backend-api lens |
| D11 可观测与诊断 | 条件 | supporting | 需要日志、指标、追踪、告警、排障 | 输出诊断信号 |
| D12 兼容与迁移 | 条件 | supporting | 数据迁移、API 兼容、灰度、回滚 | 展开迁移和回滚 |
| D13 验证策略 | 必选 | core | 任意后端变更 | 覆盖单测、集成、契约和回归 |
| D14 风险与决策 | 必选 | core | 任意后端变更 | 记录取舍和未决 |
