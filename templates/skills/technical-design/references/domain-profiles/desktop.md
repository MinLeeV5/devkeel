# Desktop Profile

适用于 Electron、Tauri、桌面壳、本地资源、preload、IPC、自动更新和原生能力。

| 维度 | 策略 | 默认优先级 | 触发条件 | 输出深度 |
|------|------|------------|----------|----------|
| D01 范围、目标与非目标 | 必选 | core | 任意桌面端变更 | 说明壳、页面、平台和非目标 |
| D02 架构边界与模块关系 | 条件 | core | 主进程、渲染进程、插件、包结构变化 | 展开进程和模块关系 |
| D03 运行边界与职责归属 | 必选 | core | Electron/Tauri/桌面端变更 | 写清主进程、preload、renderer、原生层职责 |
| D04 流程与失败路径 | 必选 | core | 启动、窗口、IPC、文件、本地服务、更新流程 | 覆盖主流程和失败路径 |
| D05 契约与接口 | 条件 | core | IPC、preload API、本地协议、插件 API 变化 | 定义白名单和调用契约 |
| D06 数据与状态 | 条件 | supporting | 本地配置、缓存、会话、窗口状态、离线数据 | 写清状态归属和生命周期 |
| D07 UI 与交互 | 条件 | core | 窗口、导航、组件、用户可见体验变化 | 展开 UI 和桌面交互状态 |
| D08 性能与资源 | 条件 | supporting | 启动耗时、内存、CPU、包体、窗口数量变化 | 使用桌面资源指标 |
| D09 可靠性与恢复 | 条件 | supporting | 崩溃恢复、窗口重建、更新失败、文件失败 | 说明恢复路径 |
| D10 安全与隐私 | 条件 | core | preload、IPC、本地文件、权限、敏感信息 | 使用 desktop lens |
| D11 可观测与诊断 | 条件 | checklist | 需要本地日志、崩溃诊断、用户反馈包 | 列诊断信号 |
| D12 兼容与迁移 | 条件 | supporting | 多平台、旧配置、自动更新、协议迁移 | 写兼容与回滚 |
| D13 验证策略 | 必选 | core | 任意桌面端变更 | 覆盖单测、端到端、平台手动验证 |
| D14 风险与决策 | 必选 | core | 任意桌面端变更 | 记录取舍和未决 |
