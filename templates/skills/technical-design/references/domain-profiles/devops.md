# DevOps Profile

适用于 CI/CD、部署、环境、发布、回滚、监控、基础设施和运行配置。

| 维度 | 策略 | 默认优先级 | 触发条件 | 输出深度 |
|------|------|------------|----------|----------|
| D01 范围、目标与非目标 | 必选 | core | 任意 DevOps 变更 | 说明环境、流水线、发布范围和非目标 |
| D02 架构边界与模块关系 | 条件 | supporting | 部署拓扑、基础设施、服务依赖变化 | 写清边界和依赖 |
| D03 运行边界与职责归属 | 条件 | supporting | CI runner、容器、主机、云资源、权限角色变化 | 写清运行位置和职责 |
| D04 流程与失败路径 | 必选 | core | 构建、部署、回滚、审批、失败恢复 | 覆盖主流程和失败路径 |
| D05 契约与接口 | 条件 | supporting | 配置、环境变量、制品、外部平台 API | 定义契约 |
| D06 数据与状态 | 条件 | checklist | 状态文件、缓存、制品、配置状态 | 简述状态归属 |
| D07 UI 与交互 | 跳过 | skip | 无用户界面 | 不展开 |
| D08 性能与资源 | 条件 | checklist | 构建耗时、资源额度、并发任务、缓存 | 简述资源策略 |
| D09 可靠性与恢复 | 条件 | core | 回滚、重试、故障隔离、不可用窗口 | 展开恢复策略 |
| D10 安全与隐私 | 条件 | core | 密钥、权限、供应链、环境隔离、发布审批 | 使用 DevOps 安全 lens |
| D11 可观测与诊断 | 条件 | supporting | 部署日志、监控、告警、审计 | 输出诊断信号 |
| D12 兼容与迁移 | 条件 | supporting | 环境迁移、配置迁移、灰度、回滚 | 展开迁移计划 |
| D13 验证策略 | 必选 | core | 任意 DevOps 变更 | 覆盖 dry-run、流水线、回滚验证 |
| D14 风险与决策 | 必选 | core | 任意 DevOps 变更 | 记录取舍和未决 |
