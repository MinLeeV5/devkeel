# Mobile Profile

适用于 iOS、Android、React Native、移动 WebView、移动端交互、离线能力和应用发布。

| 维度 | 策略 | 默认优先级 | 触发条件 | 输出深度 |
|------|------|------------|----------|----------|
| D01 范围、目标与非目标 | 必选 | core | 任意移动端变更 | 说明平台、设备、版本和非目标 |
| D02 架构边界与模块关系 | 条件 | supporting | 原生层、跨端层、模块边界变化 | 写清依赖方向 |
| D03 运行边界与职责归属 | 条件 | supporting | 原生桥、WebView、后台任务、推送、系统能力 | 写清运行位置和职责 |
| D04 流程与失败路径 | 必选 | core | 页面流、权限弹窗、网络失败、系统回调 | 覆盖主流程和失败路径 |
| D05 契约与接口 | 条件 | supporting | 原生桥、深链、推送 payload、API 变化 | 定义契约 |
| D06 数据与状态 | 条件 | core | 本地缓存、离线、会话、表单、同步 | 展开状态生命周期 |
| D07 UI 与交互 | 条件 | core | 页面、组件、手势、动效、适配变化 | 展开状态、适配和设计事实 |
| D08 性能与资源 | 条件 | supporting | 启动、帧率、内存、电量、包体、网络 | 使用移动体验指标 |
| D09 可靠性与恢复 | 条件 | supporting | 离线、重试、权限拒绝、后台恢复 | 说明恢复路径 |
| D10 安全与隐私 | 条件 | supporting | 本地敏感数据、权限、剪贴板、截屏、鉴权态 | 使用 mobile 相关 lens |
| D11 可观测与诊断 | 条件 | checklist | 崩溃、性能、用户行为、远程诊断 | 列诊断信号 |
| D12 兼容与迁移 | 条件 | supporting | OS 版本、设备尺寸、灰度、配置迁移 | 展开兼容和回滚 |
| D13 验证策略 | 必选 | core | 任意移动端变更 | 覆盖单测、真机、兼容和手动验证 |
| D14 风险与决策 | 必选 | core | 任意移动端变更 | 记录取舍和未决 |
