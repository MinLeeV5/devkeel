## 领域专项说明

**CLI/工具类：**
核心关注 R1 编码规范、R3 项目结构、R4 测试策略、R5 错误处理、R9 API 契约（命令行接口设计）、R14 依赖管理、R18 部署/CI（发布流程）、R19 文档规范（--help、README）。

**库/SDK 类：**
额外关注 R7 安全（供应链安全）、R8 性能（不拖慢消费者）、R9 API 契约（公开 API 设计）、R19 文档（API 文档质量）。

**未命中领域：**
使用 `custom:<标签>` 的项目，矩阵默认按全部 `○`（按需启用）处理，由用户在 Phase 2.2 和 Phase 3.3 中自行选择。
