update-notifier 系统架构

devkeel · Container 级视图

核心模块

  • • update-notifier.ts — 主入口 checkAndNotify()
  • • 缓存管理 — 24h TTL，JSON 持久化
  • • 版本比对 — 复用 config.ts 现有逻辑
  • • 浏览器打开 — 跨平台（open/xdg-open/start）
  • • 频率控制 — 每天最多打开一次

数据流

  • • 本地缓存优先（毫秒级比对）
  • • 过期时异步拉取 npm view（不阻塞）
  • • 首次发现更新 → CLI 提示 + 浏览器
  • • 后续提醒 → 仅 CLI 提示
  • • 异常静默降级，不影响主命令

旁路隔离

  • • 整体 try/catch 包裹，异常静默吞掉
  • • 网络请求超时 3s，失败跳过
  • • 异步执行，不阻塞命令主流程
  • • 缓存读写失败 → 视为不存在
  • • 浏览器打开失败 → 仅 CLI 提示
