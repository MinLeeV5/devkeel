01 需求背景
将 SuperPowers v5.1.0 中 opsx 流程依赖的 8 个 skill 嵌入 harness 模板，使项目 init 后即可直接使用完整工作流，无需额外安装 SuperPowers 插件。

痛点

问题影响
必须安装 SuperPowers 插件使用门槛高，多平台适配复杂
插件强制注入 hook + meta skill每次会话消耗 ~1,350 tokens
加载全部 14 个 skill 元数据只用到 8 个，浪费 context

目标用户

角色关注点
项目开发者init 后直接可用，零额外安装
多平台用户Claude Code / Codex / Cursor / Gemini CLI 统一体验
已装 SuperPowers 的用户不冲突，项目本地 skill 优先

需求边界

In Scope

  • 嵌入 8 个 skill（brainstorming、writing-plans、subagent-driven-development、executing-plans、using-git-worktrees、test-driven-development、requesting-code-review、finishing-a-development-branch）
  • 从 brainstorming 移除 visual-companion
  • 所有 superpowers: 前缀引用改为裸名
  • metadata 标注 author: "superpowers", version: "5.1.0"

Out of Scope

  • 不嵌入 using-superpowers meta skill
  • 不修改分发逻辑（现有机制已覆盖）
  • 不实现自动化上游同步

04 变更提案

Why

消除外部插件依赖，降低使用门槛。用户 init 后即可使用完整 opsx 工作流，零额外依赖、零平台差异。每次会话节省 ~1,350 tokens 的强制注入开销。

What Changes

变更FromToImpact
Skill 来源依赖 SuperPowers 插件模板直接包含非破坏性
引用前缀superpowers:brainstormingbrainstorming需 devkeel update
废弃检测仅识别 devkeel同时识别 superpowers非破坏性
brainstorming含 visual-companion移除非破坏性

Impact

范围内容
模板资产+8 个 skill 目录（~83 KB）
npm 包体积+83 KB 文本（压缩后 ~20 KB）
源码isHarnessGenerated +1 条件
已 init 项目需 devkeel update
05 规格清单
Requirement
Skills SHALL be embedded in templates

harness 模板 MUST 包含 8 个 SuperPowers skill 目录，每个含完整 SKILL.md 及附属文件。

Scenario: devkeel init copies all embedded skills

WHEN 用户执行 devkeel init

THEN .harness/skills/ 中包含 8 个 skill 目录

Requirement
Skill metadata SHALL identify source and version

每个嵌入 skill 的 SKILL.md frontmatter MUST 包含 author: "superpowers" 和 version: "5.1.0"。

Scenario: metadata present

WHEN 检查任意嵌入 skill 的 SKILL.md

THEN frontmatter 中存在 author 和 version 标注

Requirement
References SHALL use bare skill names

所有模板文件中对嵌入 skill 的引用 MUST 使用裸名，不得使用 superpowers: 前缀。

Scenario: zero superpowers: prefix in templates

WHEN grep 全部模板文件

THEN superpowers: 匹配数为 0

Requirement
brainstorming SHALL exclude visual-companion

嵌入的 brainstorming skill MUST NOT 包含 visual-companion.md 和 scripts/ 目录。

Scenario: files absent

WHEN 检查 templates/skills/brainstorming/

THEN 不存在 visual-companion.md 和 scripts/

Requirement
Deprecated detection SHALL recognize superpowers author

isHarnessGenerated MUST 将 author: "superpowers" 识别为 harness 管理资产。

Scenario: detected as harness-generated

WHEN SKILL.md 包含 author: "superpowers"

THEN isHarnessGenerated 返回 true
