需求背景

将 setup skill 从"全工具链安装器"重构为"推荐库自动配置器"，聚焦 openspec、oh-my-claudecode (OMC)、oh-my-codex (OMX) 三个工具的检测、安装与完整配置，运行时自动识别当前 Agent 类型。

当前痛点

  1. 现有 setup skill 承担了过多职责 — 从 claude-code CLI 安装到 superpowers 插件再到 harness-cli 自身
  2. SuperPowers 已内置到 harness 模板中，不需要额外安装步骤
  3. 只支持 oh-my-claudecode，不支持 oh-my-codex
  4. omc 的安装说明不完整 — 缺少 omc setup 后续配置和 teams 环境变量
  5. skill 没有运行时检测能力 — 无法判断当前在 Claude Code 还是 Codex CLI 中执行

05

规格清单

agent-detection

Requirement

Agent type detection

Setup skill SHALL 在路由到工具安装流程前检测当前 Agent 类型。

Scenario: Claude Code detected

WHEN claude --version 返回有效版本 → THEN 路由到 OMC 安装流程

Scenario: Codex CLI detected

WHEN codex --version 返回有效版本 → THEN 路由到 OMX 安装流程

Scenario: Both agents available

WHEN 两者都返回有效版本 → THEN 询问用户或全部安装

Scenario: Neither detected

WHEN 两者都不可用 → THEN 报告无支持 Agent，列出选项

Requirement

Detection MUST precede tool installation

Agent 类型检测 MUST 在任何 oh-my 工具安装步骤之前执行。

Scenario: Detection gates installation

WHEN 检测结果为 "Claude Code" → THEN 只展示 OMC 流程

openspec-setup

Requirement

openspec CLI installation

Setup skill SHALL 检测 openspec 是否安装，缺失时安装。

Scenario: Not installed

WHEN openspec --version 失败 → THEN 执行 npm install -g @fission-ai/openspec@latest

Scenario: Already installed

WHEN 已安装 → THEN 报告版本，跳过安装

Requirement

MUST NOT perform project initialization

Setup skill SHALL NOT 运行 openspec init 或 openspec update。

Scenario: Skip init

WHEN openspec 已安装 → THEN 不执行 init/update

omc-setup

Requirement

OMC CLI installation

Setup skill SHALL 在 Agent 为 Claude Code 时安装 OMC。

Scenario: Not installed

WHEN omc --version 失败且 Agent = Claude Code → THEN npm install -g oh-my-claude-sisyphus@latest

Requirement

OMC setup configuration

Setup skill SHALL 引导用户完成完整 OMC setup，MUST 区分终端和会话内命令。

Scenario: Terminal

WHEN 终端执行 → THEN 指引运行 omc setup

Scenario: In-session

WHEN Claude Code 会话内 → THEN 指引运行 /omc-setup

Requirement

OMC teams environment variable

Setup skill SHALL 确保 teams 功能已启用。

Scenario: Not configured

WHEN ~/.claude/settings.json 无 teams 变量 → THEN 指引添加 CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS: "1"

Requirement

OMC verification

Setup skill MUST 验证 OMC 安装和配置完整性。

Scenario: Success

WHEN omc --version 有效 → THEN 报告已验证，建议 /omc-doctor

omx-setup

Requirement

OMX CLI installation

Setup skill SHALL 在 Agent 为 Codex CLI 时安装 OMX。

Scenario: Not installed

WHEN OMX 不可用且 Agent = Codex → THEN npm install -g oh-my-codex

Requirement

OMX setup + doctor

Setup skill SHALL 运行 omx setup 并用 omx doctor 验证。

Scenario: Doctor passes

WHEN omx doctor 无严重错误 → THEN 报告 OMX 已验证

Requirement

OMX execution verification (optional)

Setup skill SHALL 提供可选的执行验证步骤，失败为非阻塞警告。

Scenario: Exec succeeds

WHEN omx exec 成功 → THEN 报告执行能力已验证

Scenario: Exec fails

WHEN exec 失败 → THEN 非阻塞警告，建议检查 codex login status
