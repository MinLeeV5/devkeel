# SDK Profile

适用于库、SDK、公共 API、类型定义、包发布、语义化版本和下游集成。

| 维度 | 策略 | 默认优先级 | 触发条件 | 输出深度 |
|------|------|------------|----------|----------|
| D01 范围、目标与非目标 | 必选 | core | 任意 SDK 变更 | 说明用户、能力边界和非目标 |
| D02 架构边界与模块关系 | 条件 | supporting | 包结构、入口、适配层、依赖变化 | 写清模块关系 |
| D03 运行边界与职责归属 | 条件 | checklist | 浏览器/Node/服务端/移动端多运行时 | 简述运行时支持边界 |
| D04 流程与失败路径 | 条件 | supporting | 初始化、调用链、错误模型、重试 | 说明调用和失败 |
| D05 契约与接口 | 必选 | core | 公共 API、类型、事件、配置变化 | 展开契约和兼容 |
| D06 数据与状态 | 条件 | supporting | 内部缓存、连接、会话、状态管理 | 写清状态生命周期 |
| D07 UI 与交互 | 跳过 | skip | SDK 不直接产出 UI | 不展开 |
| D08 性能与资源 | 条件 | checklist | 包体、初始化、批处理、内存变化 | 简述资源影响 |
| D09 可靠性与恢复 | 条件 | supporting | 错误模型、可重试、降级、兼容失败 | 说明恢复 |
| D10 安全与隐私 | 条件 | supporting | token、密钥、敏感数据、供应链、权限 | 使用 sdk lens |
| D11 可观测与诊断 | 条件 | checklist | debug、trace、错误码、下游排障 | 列诊断信号 |
| D12 兼容与迁移 | 必选 | core | 任意公共 API 或包发布变更 | 展开版本兼容和迁移 |
| D13 验证策略 | 必选 | core | 任意 SDK 变更 | 覆盖类型、单测、契约和下游样例 |
| D14 风险与决策 | 必选 | core | 任意 SDK 变更 | 记录取舍和未决 |
