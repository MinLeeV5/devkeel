# Frontend Profile

适用于 Web UI、浏览器运行时、组件、路由、样式、状态管理、前端构建和可访问体验。

| 维度 | 策略 | 默认优先级 | 触发条件 | 输出深度 |
|------|------|------------|----------|----------|
| D01 范围、目标与非目标 | 必选 | core | 任意前端变更 | 说明页面、组件、状态和非目标 |
| D02 架构边界与模块关系 | 条件 | supporting | 跨页面、跨包、状态层或构建链路变化 | 写清模块关系和依赖方向 |
| D03 运行边界与职责归属 | 条件 | supporting | 涉及浏览器、服务端渲染、WebView、插件或宿主壳 | 写清代码运行在哪里、谁负责什么 |
| D04 流程与失败路径 | 必选 | core | 用户操作、数据加载、提交、错误处理 | 覆盖主流程和失败态 |
| D05 契约与接口 | 条件 | supporting | 接口、事件、组件 props、路由参数变化 | 定义输入输出和兼容 |
| D06 数据与状态 | 必选 | core | 表单、缓存、全局状态、乐观更新 | 说明状态来源和同步策略 |
| D07 UI 与交互 | 必选 | core | 任意用户可见 UI/交互变化 | 展开 UI 意图、状态、适配和设计事实 |
| D08 性能与资源 | 条件 | supporting | 首屏、交互延迟、包体、渲染性能、内存变化 | 使用前端体验指标 |
| D09 可靠性与恢复 | 条件 | checklist | 离线、重试、错误恢复、降级体验 | 简述恢复路径 |
| D10 安全与隐私 | 条件 | supporting | XSS、鉴权态、敏感信息、跨域、三方脚本 | 使用 frontend lens |
| D11 可观测与诊断 | 条件 | checklist | 需要埋点、错误上报、性能诊断 | 列出诊断信号 |
| D12 兼容与迁移 | 条件 | supporting | 浏览器兼容、路由迁移、组件 API 迁移 | 写兼容和回滚 |
| D13 验证策略 | 必选 | core | 任意前端变更 | 覆盖单测、交互、视觉或手动验证 |
| D14 风险与决策 | 必选 | core | 任意前端变更 | 记录取舍和未决 |
