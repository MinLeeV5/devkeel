# CLI Profile

适用于命令行工具、子命令、参数解析、终端输出、本地文件系统和脚本集成。

| 维度 | 策略 | 默认优先级 | 触发条件 | 输出深度 |
|------|------|------------|----------|----------|
| D01 范围、目标与非目标 | 必选 | core | 任意 CLI 变更 | 说明命令、参数、用户和非目标 |
| D02 架构边界与模块关系 | 条件 | supporting | 命令模块、库层、执行器、插件变化 | 写清模块关系 |
| D03 运行边界与职责归属 | 条件 | supporting | 本地命令、外部进程、shell、平台差异 | 写清本地职责和外部依赖 |
| D04 流程与失败路径 | 必选 | core | 命令执行、交互输入、失败退出、重试 | 覆盖退出码和错误路径 |
| D05 契约与接口 | 必选 | core | 参数、配置、stdout/stderr、JSON 输出变化 | 定义命令契约 |
| D06 数据与状态 | 条件 | supporting | 配置文件、缓存、临时文件、锁文件 | 说明文件和状态生命周期 |
| D07 UI 与交互 | 条件 | supporting | 交互式 prompt、终端表格、颜色、进度 | 输出终端交互状态 |
| D08 性能与资源 | 条件 | checklist | 大文件、扫描、网络请求、冷启动明显变化 | 简述资源策略 |
| D09 可靠性与恢复 | 条件 | supporting | 幂等、可重跑、部分失败、网络失败 | 说明恢复和清理 |
| D10 安全与隐私 | 条件 | supporting | token、路径、shell 注入、权限、日志脱敏 | 使用 cli lens |
| D11 可观测与诊断 | 条件 | checklist | debug 日志、verbose、错误定位 | 列诊断信号 |
| D12 兼容与迁移 | 条件 | supporting | 命令兼容、配置升级、脚本用户 | 写兼容和迁移 |
| D13 验证策略 | 必选 | core | 任意 CLI 变更 | 覆盖单测、快照、命令级验证 |
| D14 风险与决策 | 必选 | core | 任意 CLI 变更 | 记录取舍和未决 |
