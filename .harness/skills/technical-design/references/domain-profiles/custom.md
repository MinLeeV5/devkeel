# Custom Profile

适用于项目专属领域、业务 DSL、插件体系、实验性运行时或无法明确归入其他 profile 的变更。

| 维度 | 策略 | 默认优先级 | 触发条件 | 输出深度 |
|------|------|------------|----------|----------|
| D01 范围、目标与非目标 | 必选 | core | 任意 custom 领域变更 | 说明领域边界和非目标 |
| D02 架构边界与模块关系 | 条件 | supporting | 领域模型、插件、模块、边界变化 | 写清关系 |
| D03 运行边界与职责归属 | 条件 | supporting | 运行时、宿主、插件、沙箱、外部执行器变化 | 写清运行位置和职责 |
| D04 流程与失败路径 | 条件 | core | 领域流程、状态变化、失败恢复 | 展开主流程和失败路径 |
| D05 契约与接口 | 条件 | core | DSL、协议、插件 API、配置契约变化 | 定义契约 |
| D06 数据与状态 | 条件 | supporting | 领域状态、缓存、存储、迁移 | 写清状态 |
| D07 UI 与交互 | 条件 | supporting | 有用户可见体验 | 按 D07 判断 |
| D08 性能与资源 | 条件 | checklist | 有资源或体验压力 | 简述指标 |
| D09 可靠性与恢复 | 条件 | supporting | 故障传播、重试、回滚、恢复 | 说明恢复 |
| D10 安全与隐私 | 条件 | supporting | 权限、敏感信息、沙箱、外部输入 | 使用最贴近 lens |
| D11 可观测与诊断 | 条件 | checklist | 需要排障或审计 | 列诊断信号 |
| D12 兼容与迁移 | 条件 | supporting | 历史数据、旧 DSL、旧插件、版本兼容 | 写兼容和迁移 |
| D13 验证策略 | 必选 | core | 任意 custom 领域变更 | 覆盖领域用例和回归 |
| D14 风险与决策 | 必选 | core | 任意 custom 领域变更 | 记录取舍和未决 |
