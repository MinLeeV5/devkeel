# D07 UI 与交互

## 目标

设计用户可见的页面、组件、交互和状态变体。涉及高保真还原时，本维度只描述需要对齐的设计事实和验证目标；是否调用其他 UI 专项技能由上层编排决定。

## 启用后的判断

- 有设计事实：设计稿、截图、线框、明确视觉参考、Figma 节点或产品现状。输出范围、结构、视觉、交互状态和运行时验证目标。
- 无设计事实：不要假装高保真。只输出 UI 意图、组件边界、状态矩阵、适配策略和待补事实。

## 输出契约

- UI 范围：整页、区块、组件、状态变体，哪些不属于本次实现。
- 组件边界：容器、子组件、数据来源、事件出口和复用关系。
- 运行边界与职责归属：哪些属于页面/组件，哪些属于宿主壳、路由、全局状态或设计系统。
- 状态矩阵：default、loading、empty、error、disabled、selected、editing 等。
- 交互路径：点击、输入、切换、提交、取消、回退和失败反馈。
- 适配策略：桌面、移动、窗口尺寸、内容溢出、可访问性。
- 失真风险：间距、层级、字体、资源、对齐、滚动、状态遗漏。
- 验证方式：截图对比、组件测试、Playwright、人工检查或设计评审。

## 完成检查

- [ ] 已说明是否存在设计事实。
- [ ] 有设计事实时已列出关键还原点和验证目标。
- [ ] 无设计事实时已列出待补事实，没有伪造细节。
- [ ] 状态矩阵覆盖非默认态。
